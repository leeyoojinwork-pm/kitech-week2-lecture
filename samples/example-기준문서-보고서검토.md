# 기준문서.md — 분기 보고서 빨간펜 검토 에이전트

> 회의록과는 다른 도메인 예시. **다른 업무도 같은 구조로 채울 수 있다**는 것을 보여주는 샘플.

---

## 1. 이 업무가 무엇인가

- **업무 이름:** 분기 R&D 보고서 1차 검토 (빨간펜)
- **언제 발생하나:** 매 분기 마감 1주일 전 (3월말, 6월말, 9월말, 12월말)
- **누가 받아보나:** 보고서 작성자 본인 — 부서장 보고 전 셀프 점검용
- **목적 한 줄:** 부서장이 가장 자주 지적하는 5개 항목을 사전에 잡아내기

## 2. 입력으로 받는 것

- **형태:** Markdown 또는 .docx 변환 텍스트
- **개수/길이:** 1편당 평균 8~12페이지 (3,000~5,000 단어)
- **반드시 포함되는 것:** 표지(과제명·작성자·기간), 요약, 본문, 결론
- **있으면 좋고 없어도 되는 것:** 부록, 참고문헌

## 3. 출력으로 내야 하는 것

- **형식:** Markdown 표 + 페이지 단위 코멘트
- **분량:** A4 1~2페이지 압축 (지적사항이 많아도 핵심 5개만)
- **반드시 들어가야 할 항목:**
  - [x] 지적사항 우선순위 표 (5개 이내)
  - [x] 페이지/문단 위치 명시
  - [x] 어떻게 고치면 좋은지 한 줄 제안
- **들어가면 안 되는 것:** 단순 오탈자(맞춤법 검사기에 맡기기), 디자인/레이아웃 코멘트

## 4. 분류·판단 기준 (가장 중요)

| 항목 | 판단 기준 |
|------|-----------|
| 우선순위 1 — 치명 | 데이터 출처 누락 / 결론과 본문 모순 / 예산 숫자 자릿수 오류 |
| 우선순위 2 — 중요 | 핵심 지표가 표 없이 본문에만 있음 / 도식 캡션 없음 / 약어 첫 등장 시 풀어쓰기 안 됨 |
| 우선순위 3 — 권고 | 단락이 7줄 초과 / 능동형으로 바꿀 수 있는 수동태 / 같은 동사 3회 이상 반복 |
| **무시할 것** | 단순 오탈자, 띄어쓰기, 줄바꿈, 폰트, 색상 |
| **확인 필요로 표시** | "약 ~정도", "추정컨대" 같은 모호한 수치 표현 — 출처 확인 후 판단 |

## 5. 톤 / 문체 / 표현 규칙

- **금지 표현:** "수정 요망", "재작성 바람" — 명령조 X
- **권장 표현:** "~을 [어떻게] 보강하면 좋겠습니다", "~을 표로 분리하는 것을 권장드립니다"
- **약어 처리:** 보고서 본문이 약어를 안 풀었으면 첫 등장 위치를 함께 명시 ("p.3, AI → 풀어쓰기 권장")
- **숫자 표기:** 출처 없는 숫자는 모두 "[출처 확인 필요]" 추가

## 6. 예외 처리

| 상황 | 처리 방식 |
|------|-----------|
| 핵심 정보가 누락됨 | "**누락 항목**" 섹션을 별도로 만들어 정리 |
| 두 가지 해석이 가능함 | 두 해석을 모두 적고 작성자에게 어떤 의도였는지 묻기 |
| 데이터가 모순됨 | 우선순위 1로 자동 분류, 두 곳의 페이지 모두 명시 |
| 외부 자료 인용이 정확한지 모름 | 검증 시도하지 말고 "원전 확인 필요"로 표시 |

## 7. 좋은 결과 vs 나쁜 결과

**좋은 결과 예시:**
```markdown
## 우선순위 지적사항 (5개)

| # | 위치 | 분류 | 내용 | 제안 |
|---|------|------|------|------|
| 1 | p.5 §3.2 | 치명 | 1분기 매출 "2.3억" → 표(p.7)는 "2.3천만" | 자릿수 통일 후 한 곳에서 인용 |
| 2 | p.4 §3.1 | 치명 | "친환경 소재 시장 성장" 출처 없음 | 산업통계 또는 시장보고서 출처 추가 |
| 3 | p.8 §4 | 중요 | AI 약어 첫 등장이지만 풀어쓰기 없음 | "AI(Artificial Intelligence)" 한 번만 |
| 4 | p.10 §5 | 중요 | 결론에서 본문에 없는 "B 기관 협력" 등장 | 본문 §3에 추가 또는 결론에서 삭제 |
| 5 | p.6 §3.3 | 권고 | 단락 11줄 (긴 호흡) | 지표 부분을 별도 표로 분리 |
```

**나쁜 결과 예시 (이렇게 나오면 다시 고쳐야 함):**
```
- 오탈자가 좀 있어요 (p.3, p.5, p.9...)
- 표가 더 있으면 좋겠어요
- 결론이 약해요
- 더 다듬어주세요
```
→ 위치·분류·구체적 제안 모두 빠짐. 작성자가 어디서부터 손대야 할지 모름.

## 활용 안내

이 양식을 본인 업무로 바꾸려면:
1. **섹션 1의 "업무 이름"부터 다시** — 이게 바뀌면 나머지가 다 바뀜
2. **섹션 4(분류 기준)에 가장 많이 시간 투자** — 부서장이 자주 지적하는 패턴 5~10개를 평소 메모해두면 좋음
3. **첫 결과는 50점 예상 정상** — 지적사항이 너무 많거나/너무 적거나 둘 중 하나, 거기서 기준을 더 정교화
