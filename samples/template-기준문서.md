## 4. 분류·판단 기준 (가장 중요)

평소에 사람이 **자동으로** 하는 분류·판단을 글로 옮기세요. AI가 가장 자주 틀리는 부분입니다.

| 항목 | 판단 기준 (구체적으로) |
|------|------------------------|
| | |
| | |
| | |

> 예시:
> - "결정사항 vs 논의 중" → 동사가 과거형/완료형이고 모두가 동의했으면 결정, 그 외는 논의
> - "이상값 vs 정상" → 평균 ± 3σ 밖이면 이상, 단 [예외 상황]은 정상
> - "공식 톤 vs 비공식" → 부서장 이상 보고서면 공식체, 팀 내부면 비공식

## 활용 안내 (지우고 사용)

작성 순서 추천:
1. 섹션 1, 2, 3을 먼저 채움 — **무엇을 받고 무엇을 낼지** 정리
2. 섹션 4를 시간 들여 작성 — **여기가 80% 결정** (성의 있게)
3. 섹션 5, 6, 7은 첫 결과 본 뒤 보강 — 한 번에 다 못 채움

채워진 직후 Claude한테 시키는 법:
> "첨부한 `기준문서.md`의 기준 그대로 따라서 [이 입력]을 처리해줘. 추측 금지 — 원본에 없는 건 [확인 필요]로 표시."
