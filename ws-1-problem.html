문제 좁히기 5칸 워크시트

본인 업무에서 첫 에이전트가 다룰 “가장 작은 반복 단위”를 정합니다.

목표는 멋진 최종 결과물이 아니라 오늘 30분 안에 한 번 돌려볼 수 있는 첫 스킬을 찾는 것입니다. 막히면 “첫 번째 스킬 이름이 뭔가요?”부터 다시 물어보세요.

5칸 채우기

1. 반복 업무내가 자주 반복하는 일은 무엇인가?
2. 입력AI에게 넣을 파일, 표, 문서, 텍스트는 무엇인가?
3. 출력AI가 뽑아줘야 하는 결과 형태는 무엇인가?
4. 판단 기준좋은 결과와 아쉬운 결과를 가르는 기준은 무엇인가?
5. 첫 스킬 이름한 줄 명령으로 부른다면 이름은 무엇인가?

좋은 문제정의 체크

  • 입력과 출력이 한 문장으로 보인다.
  • 사람이 마지막에 확인해야 할 지점이 남아 있다.
  • 데이터 파일을 지금 바로 준비할 수 있다.
  • 최종 산출물 전체가 아니라, 첫 단계 하나만 다룬다.

복붙 프롬프트

내 업무에서 첫 AI 에이전트로 만들 수 있는 가장 작은 반복 단위를 찾아줘.

아래 내용을 기준으로 문제정의를 좁혀줘.
1. 반복 업무:
2. 현재 사용하는 입력 자료:
3. 원하는 출력물:
4. 사람이 판단하는 기준:
5. 오늘 30분 안에 테스트 가능한 범위:

결과는 "스킬 이름 / 입력 / 출력 / 판단 기준 / 첫 테스트 방법"으로 정리해줘.
