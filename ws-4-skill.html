실습 ④ · 스킬 구축

스킬 구축 워크시트

반복 업무를 한 줄 명령으로 다시 부를 수 있게 이름, 입력, 출력, 기준을 고정합니다.

스킬은 거창한 프로그램이 아니라, 반복해서 쓰는 업무 기준을 묶어둔 작은 도구입니다. 한 번에 전체 업무를 만들기보다 가장 작은 반복 단위 하나부터 시작하세요.

스킬 명세 5칸

1. 스킬 이름명령처럼 부를 수 있는 짧은 이름을 붙입니다.
2. 언제 쓰는가이 스킬을 호출하는 상황을 정합니다.
3. 필요한 입력파일, 표, 문서, 텍스트, 배경 설명을 적습니다.
4. 처리 기준암묵지 형식화에서 뽑은 판단 기준을 넣습니다.
5. 출력 형태표, 문단, 체크리스트, 메일 초안 등 결과 형태를 고정합니다.

작성 예시

스킬은 이름보다 입력, 처리 기준, 출력 형태가 명확해야 재사용할 수 있습니다.

예시 답안 · /뉴스-한문장-작성
뉴스 선별과 한 문장 초안을 만드는 스킬
스킬 이름/뉴스-한문장-작성
사용 상황매일 오전 주요 뉴스 후보를 확인하고 배포용 문장 초안을 만들 때
입력뉴스 URL 목록, 기사 본문, 매체명, 발행일, 과거 우수 문장 예시
처리 기준포함·제외 기준 적용, 중복 기사 제거, 한 기사 한 문장, 과장 표현 제외
출력 형태선별 기사 표: 매체명, 제목, 포함 사유, 한 문장 초안, 담당자 확인 항목
실패 시 확인중복 기사 포함 여부, 기관 관련성 판단, 문장 길이, 출처 누락 여부
예시 답안 · /원규-검토
공공기관 규정 개정안을 5가지 관점으로 검토하는 스킬
스킬 이름/원규-검토
사용 상황원규 개정안 초안을 부서 검토 전에 1차 점검할 때
입력개정안 파일, 기존 규정, 검토 요청 배경, 관련 상위 지침
처리 기준법적 정합성, 재무적 타당성, 운영 실행가능성, 위험 관리, 전략 정합성
출력 형태관점별 검토 의견표, 보완 필요 항목, 담당자에게 확인할 질문 목록
사람 검토최종 의견 확정, 법적 판단, 대외 제출 문구는 담당자가 확인

첫 테스트 기준

  • 샘플 입력 1개로 실행해본다.
  • 예상 출력과 실제 출력을 비교한다.
  • 틀린 결과를 보고 기준 문장을 1개 추가한다.
  • 다시 실행해서 개선 여부를 확인한다.
