# CLAUDE.md

> 이 파일은 Claude가 이 프로젝트 폴더에서 작업할 때 **자동으로 읽는** 안내서입니다.
> 매 대화마다 이걸 먼저 보고 그 안에 적힌 규칙을 따르려고 합니다.

## 이 프로젝트는 무엇인가

[한 줄로 적기 — 예: "기술 동향 논문·기사를 받아 핵심 3줄 + 시사점으로 요약하는 에이전트"]

## 폴더 구조

```
프로젝트/
├── CLAUDE.md          ← 이 파일 (Claude에게 주는 지침)
├── 기준문서.md         ← 업무 기준 (이 폴더에서 가장 중요한 파일)
├── data/              ← 처리할 원본 파일들
│   └── (논문, 기사, 회의 녹취 등)
└── output/            ← 결과물 저장 위치
    └── (날짜별 결과 파일)
```

## 작업 시 반드시 지킬 것

1. **`기준문서.md` 를 먼저 읽고** 그 기준대로 작업한다.
2. **출력은 항상 `output/` 폴더에** 날짜 포함 파일명으로 저장 (`결과_YYYYMMDD.md`).
3. **원본은 절대 수정하지 않는다** — `data/` 폴더 파일은 읽기만.
4. **추정 금지** — 원본에 없는 내용은 `[확인 필요]` 로 표시.
5. **모르는 약어/고유명사**가 나오면 임의로 해석하지 말고 사용자에게 묻는다.

## 결과물 톤

- 한국어
- 격식체 ("~합니다") — 보고용 문서 기준
- 불릿(-) 또는 번호 매기기, 표 적극 활용
- 영어 약어는 처음 등장 시 풀어쓰기 "(Artificial Intelligence, AI)"

## 자주 쓰는 명령

- `data/ 안의 파일 전부 요약해줘` — 일괄 처리
- `[파일명] 만 다시 요약해줘` — 단일 파일
- `오늘 날짜로 결과 합쳐서 한 파일로 만들어줘` — 일일 보고

## 활용 안내 (지우고 사용)

이 양식의 핵심:
- **CLAUDE.md는 자동 로드** — Claude가 모든 대화에서 자동으로 읽음
- **기준문서.md는 별도 첨부 또는 본 파일에서 참조 지시** — 도메인 기준의 SSOT(Single Source of Truth)
- **명령은 짧게** — 매번 긴 지시 대신 CLAUDE.md에 규칙을 박아두고 단축 명령으로
