## GitHub Pages 배포

1. 이 저장소를 GitHub에 push
2. Settings → Pages → Source: `main` 브랜치, `/` (root) 선택
3. 저장 후 잠시 기다리면 배포 완료

## 파일 구성

```
index.html          ← GitHub Pages 배포 파일 (메인)

README.md           ← 이 파일
```
