# [스킬 이름] 스킬

> Claude Code에서 `/스킬이름` 으로 호출되면 자동 적용되는 지침 파일.
> 한 번 만들어두면 새 대화마다 같은 결과 품질을 유지할 수 있습니다.

## 언제 작동하나

- 사용자가 직접 호출: `/스킬이름`
- 자동 트리거: description 안에 적은 키워드(예: "회의록 정리해줘")가 사용자 메시지에 등장할 때

## 이 스킬이 하는 일 (3줄)

1. _____________________________________________________________
2. _____________________________________________________________
3. _____________________________________________________________

## 작업 순서

### Step 1 — 입력 파악
사용자가 다음 중 무엇을 줬는지 먼저 확인한다:
- 파일 경로 (예: `data/회의-2025-04-22.md`)
- 첨부 파일 (드래그 앤 드롭)
- 본문 안에 직접 붙여넣은 텍스트

→ 모호하면 진행 전에 사용자에게 묻는다.

### Step 2 — 기준 적용
다음 기준을 빠짐없이 적용한다:

- [ ] [기준 1 — 구체적으로]
- [ ] [기준 2]
- [ ] [기준 3]
- [ ] [기준 4]

### Step 3 — 출력 형식
결과는 다음 구조로 낸다:

```
[헤딩 1]
- ...
- ...

[헤딩 2]
| 컬럼 A | 컬럼 B |
|--------|--------|
| ...    | ...    |
```

## 절대 하지 말 것 (Negative)

- 원본에 없는 내용 추측·창작 금지 — 모르면 "[확인 필요]"
- 원본 파일 수정 금지 (읽기만)
- 이모지 / 불필요한 인사말 / "아래는 ~입니다" 같은 메타 표현 금지
- 길이 늘리기 위한 반복·말 늘리기 금지

## 결과를 사용자에게 줄 때

- 항상 결과 파일 경로를 마지막에 명시: `→ output/결과_YYYYMMDD.md`
- 한 번에 다 끝났는지, 추가 확인 필요한 부분이 있는지를 한 줄로 요약

## 자주 묻는 후속 작업

- "다시 더 짧게 해줘" → 출력 분량을 절반으로
- "더 격식체로" → 톤만 바꾸고 내용은 유지
- "표를 글머리로 바꿔줘" → 형식 변환만, 분류 기준은 그대로

## 활용 안내 (지우고 사용)

저장 위치:
- **개인용**: `~/.claude/skills/스킬이름/SKILL.md`
- **프로젝트용**: `[프로젝트 폴더]/.claude/skills/스킬이름/SKILL.md`

확인 방법:
- Claude Code 시작 후 `/skills` 입력 → 목록에 뜨는지 확인
- 직접 호출: `/스킬이름 [요청]`
- 자동 트리거 테스트: description의 키워드를 자연스럽게 포함한 요청 던져보기

진화시키는 법:
1. 첫 결과를 보고 빠진 기준을 메모
2. SKILL.md의 "Step 2 — 기준 적용" 섹션에 추가
3. 같은 입력으로 다시 돌려서 개선됐는지 확인
4. 5번 정도 사이클 돌리면 안정적인 스킬 완성
