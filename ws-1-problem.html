문제 좁히기 5칸 워크시트

본인 업무에서 첫 스킬이 다룰 “가장 작은 반복 단위”를 정합니다.

목표는 최종 결과물을 한 번에 만드는 것이 아니라 오늘 30분 안에 한 번 실행해볼 수 있는 첫 스킬을 정하는 것입니다. 막히면 “이번 주에 검증할 첫 실행 단위는 무엇인가”부터 다시 확인합니다.

5칸 채우기

1. 반복 업무내가 자주 반복하는 일은 무엇인가?
2. 입력처리에 사용할 파일, 표, 문서, 텍스트는 무엇인가?
3. 출력결과물은 표, 초안, 체크리스트 중 어떤 형태인가?
4. 판단 기준우수 결과와 보완 결과를 가르는 기준은 무엇인가?
5. 첫 스킬 이름한 줄 명령으로 부른다면 이름은 무엇인가?

작성 예시

멘토 사례를 바탕으로 이 정도까지 좁히면 첫 테스트를 시작할 수 있습니다.

예시 답안 · 데일리 뉴스 작성 지원
넓은 목표를 “뉴스 선별 + 한 문장 초안”으로 줄인 사례
1. 반복 업무매일 아침 기관 관련 뉴스 50건을 확인하고 주요 기사 10건을 골라 배포용 문장을 작성한다.
2. 입력뉴스 URL 목록, 기사 본문, 매체명, 발행일, 과거 우수 요약문 10개
3. 출력선별 기사 10건과 각 기사별 한 문장 요약 초안
4. 판단 기준우리 원 직접 언급은 우선 포함, 동일 사안 3차 후속은 제외, 정치 쟁점 중심 기사는 보류 표시
5. 첫 스킬 이름/뉴스-한문장-작성
첫 테스트 방법오늘 기사 10건만 넣고, 사람이 고른 기사 목록과 비교한다.

문제정의 체크

  • 입력과 출력이 한 문장으로 보인다.
  • 사람이 마지막에 확인해야 할 지점이 남아 있다.
  • 데이터 파일을 지금 준비할 수 있다.
  • 최종 산출물 전체가 아니라, 첫 단계 하나만 다룬다.

점검 프롬프트

내 업무에서 첫 스킬로 만들 수 있는 가장 작은 반복 단위를 찾아줘.

아래 내용을 기준으로 문제정의를 좁혀줘.
1. 반복 업무:
2. 현재 사용하는 입력 자료:
3. 원하는 출력물:
4. 사람이 판단하는 기준:
5. 오늘 30분 안에 테스트 가능한 범위:

결과는 "스킬 이름 / 입력 / 출력 / 판단 기준 / 첫 테스트 방법"으로 정리해줘.
