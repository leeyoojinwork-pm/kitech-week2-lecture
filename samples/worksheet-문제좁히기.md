## 3. 4분면 매트릭스에 단계 배치

각 단계를 임팩트(반복적·시간 소모) × 실현가능성(데이터·매뉴얼·암묵지 정리도)으로 평가:

```
임팩트 高
   ↑
   │  [2사분면 — 데이터·매뉴얼 먼저]   │  [1사분면 — 즉시 실행] ★
   │                                  │
   │   ① ...                          │   ② ...
   │                                  │
   │──────────────────────────────────┼──────────────────────────────────
   │  [4사분면 — 보류]                │  [3사분면 — 보너스]
   │                                  │
   │   ③ ...                          │   ④ ...
   │                                  │
   └──────────────────────────────────────────────→ 실현가능성 高
```

> **1사분면에 배치한 단계 중 가장 우상단(가장 반복적 + 가장 기준 명확) 1개에 ⓞ**

## 4. 자기 검증 — 정말 좁혀졌나?

다음 4개에 모두 ✓ 가 들어가야 "이번 주 안에 작동" 가능:

- [ ] 입력 형태가 한 종류 (PDF / 텍스트 / 표 등 하나로 고정)
- [ ] 출력 형식을 한 줄로 설명할 수 있음
- [ ] 매번 같은 판단을 사람도 할 수 있음 (= 기준 문서화 가능)
- [ ] 잘못된 결과를 봐도 "어디가 틀렸는지" 즉시 알 수 있음

✗ 가 하나라도 있으면 더 좁힐 수 있습니다. 1단계로 돌아가 그 단계를 또 쪼개세요.
